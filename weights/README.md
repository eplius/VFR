# Model assets

Place the release assets `vfr_s_coco.pt` and `vfr_m_coco.pt` here.
Their companion JSON manifests record SHA-256 checksums, fixed inference
settings, and source-checkpoint epoch. The `.pt` files include inference graphs
and parameters only, not optimizers, training configuration, or training data.

Download models only from a trusted publisher. TorchScript models are executable
artifacts. Do not load untrusted files.
